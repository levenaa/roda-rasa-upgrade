RODA RASA — DEMO WEBSITE

Cara pakai:
1. Ekstrak folder/ZIP ini.
2. Buka folder roda-rasa-upgrade di VS Code.
3. Buka index.html dengan Live Server.
4. Edit jadwalLokasi, nomorWhatsApp, dan daftarMenu di script.js.

Penting:
- Data lokasi, nomor WA, menu, harga, dan foto masih contoh.
- Ganti alamat setiap hari dengan alamat yang benar agar tautan Google Maps akurat.
- Foto demo dimuat dari Unsplash dan membutuhkan koneksi internet.
- Untuk memakai foto asli, letakkan foto di folder images lalu ubah nilai foto menjadi misalnya "images/burger.jpg".
